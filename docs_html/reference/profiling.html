Profiling#

Profiling decorators for queues and listeners.

They wrap an existing queue or listener, delegate every call to it, and measure how many times its main methods are called and how long they take:

queue = ProfiledQueue(InMemoryQueue())
listener = ProfiledListener(MyListener())
channel.register_connection(Connection(listener=listener, queue=queue))
...
print(queue.push_stats.calls, queue.push_stats.total_time, listener.on_message_stats.mean_time)

class ProfiledQueue#

Bases: Queue[MIn, MOut]

Wraps a queue and profiles its push(), pop() and wait_pop().

Times include waiting: a wait_pop() or a pop() with a timeout lasts until a message arrives, or the timeout expires. Empty pops raising a NoMessagesException are counted too.

async wait_pop(timeout)#

Waits for the next message without blocking the event loop.

The default implementation runs pop() with timeout in a worker thread, so it takes one thread per waiting call. Override it with a native async wait when possible.

Parameters:

timeout (float) – Seconds to wait for a message.

Return type:

MOut

Raises a NoMessagesException if no message arrives within timeout.
