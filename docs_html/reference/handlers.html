Error handlers#

class QueuingErrorHandler#

Handles errors raised by queues, see add_queuing_error_handler().

Methods do nothing by default: override the ones you need.

handle_push_error(connection_id, msg, exception)#

Called when pushing msg to the queue of connection connection_id fails. The exception is re-raised afterwards.

Parameters:

  • connection_id (str)

  • msg (MessageContract)

  • exception (Exception)

Return type:

None

handle_pop_error(connection_id, exception)#

Called when popping from the queue of connection connection_id fails. The exception is re-raised afterwards.

Parameters:

  • connection_id (str)

  • exception (Exception)

Return type:

None

class ListenerErrorHandler#

Handles errors raised by listeners, see add_listener_error_handler().

Methods do nothing by default: override the ones you need.

handle_on_message_error(connection_id, msg, exception)#

Called when on_message() of connection connection_id fails. The exception is not re-raised: msg is delivered anyway.

Parameters:

  • connection_id (str)

  • msg (MessageContract)

  • exception (Exception)

Return type:

None
